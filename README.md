# aa-calc

AA (going-Dutch) bill-split calculator.

## Current app

The maintained UI is in [`new-react-app/`](./new-react-app) (Vite + React + TypeScript).

```bash
cd new-react-app
npm ci
npm run dev
```

## Legacy

- `src/` — older Taro multi-end scaffold
- `old/` — earlier browser prototype
